# LessonFlow

Адаптивное веб-приложение для расписания репетитора английского языка.

## Возможности

- расписание на сегодня и календарь на неделю;
- карточки учеников с целью обучения, возрастом, уровнем, контактом, ставкой и заметками;
- статусы занятий: запланировано, проведено, отменено;
- учёт оплаты и обзор ожидаемого дохода;
- повтор занятия раз в неделю на 4 недели;
- поиск учеников;
- защищённый вход по email и паролю;
- облачная синхронизация через Firebase между устройствами;
- экспорт и импорт дополнительной резервной копии;
- установка на телефон как веб-приложения (PWA);
- адаптивный интерфейс для компьютера и смартфона.

## Как пользоваться

1. Откройте раздел «Ученики» и добавьте ученика.
2. Нажмите «Добавить занятие» и заполните дату, время и тему.
3. После урока измените статус на «Проведено» и отметьте оплату.
4. Периодически скачивайте резервную копию в разделе «Настройки».

Основная копия данных хранится в Cloud Firestore в европейском регионе. Правила базы разрешают читать и изменять документ только тому пользователю, чей Firebase UID совпадает с ID документа. Локальная копия остаётся в браузере для устойчивой работы, а для дополнительной страховки доступен экспорт JSON-файла.

При первом открытии создайте аккаунт по email и паролю. В дальнейшем тот же аккаунт открывает единое расписание на любом устройстве.

## Локальный запуск

Проект не требует сборки или установки зависимостей:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Публикация

Workflow в `.github/workflows/pages.yml` автоматически публикует сайт в GitHub Pages после каждого изменения ветки `main`.
