# LessonFlow

Адаптивное веб-приложение для расписания репетитора английского языка.

## Возможности

- расписание на сегодня и календарь на неделю;
- карточки учеников с уровнем, контактом, ставкой и заметками;
- статусы занятий: запланировано, проведено, отменено;
- учёт оплаты и обзор ожидаемого дохода;
- повтор занятия раз в неделю на 4 недели;
- поиск учеников;
- экспорт и импорт резервной копии;
- установка на телефон как веб-приложения (PWA);
- адаптивный интерфейс для компьютера и смартфона.

## Как пользоваться

1. Откройте раздел «Ученики» и добавьте ученика.
2. Нажмите «Добавить занятие» и заполните дату, время и тему.
3. После урока измените статус на «Проведено» и отметьте оплату.
4. Периодически скачивайте резервную копию в разделе «Настройки».

Данные хранятся в браузере на текущем устройстве. Сервер и регистрация не требуются. Для переноса данных используйте экспорт и импорт JSON-файла.

## Локальный запуск

Проект не требует сборки или установки зависимостей:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Публикация

Workflow в `.github/workflows/pages.yml` автоматически публикует сайт в GitHub Pages после каждого изменения ветки `main`.
